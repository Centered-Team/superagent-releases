# Superagent releases

Downloads of [Superagent](https://github.com/Centered-Team/superagent), a desktop app that runs several Claude Code agents on one project.

**[Download the latest version](https://github.com/Centered-Team/superagent-releases/releases/latest)**: the `.dmg` file, for Macs with Apple Silicon and macOS 13 or later. Open it and drag Superagent to Applications.

Superagent updates itself. This repo holds only the built releases. The release workflow in the source repo publishes them.
